# Snippets

Reusable code fragments organized by language or framework.

## Layout

- `python/`
- `shell/`
- Add a new folder when a language has more than a few snippets.

## Conventions

- Each snippet is a small, complete, and self-contained example.
- Name files descriptively (e.g., `retry-with-backoff.py`).
- Include a one-line comment at the top describing what the snippet does.
