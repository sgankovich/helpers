# AI Resources

This directory contains resources for AI-assisted development: prompts, skills, and agent conventions.

## Layout

- `prompts/` — versioned LLM prompt templates and prompt-engineering notes.
- `skills/` — modular capabilities or instructions for AI agents.

## Conventions

- Use descriptive, kebab-case file names.
- Include a short frontmatter block or header comment describing the purpose.
- Keep prompts focused on a single task or role.
- Version significant prompt changes in the file history rather than duplicating files.
